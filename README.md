# 长期记忆 AI 助理 · 交互原型

以「项目」为单位沉淀对话中产生的决策理由与口径：记忆写入前经用户确认、调用时可溯源、出错后可纠正并全局生效。

在线访问：<https://ruruko-1024.github.io/long_memory_agent/>

## 演示路径

点击页面上方五个时点按钮依次体验：

| 时点 | 演示内容 |
|---|---|
| Week 1 | 抽取候选记忆，写入前逐条确认 |
| Week 3 | 主动调出既有阈值，记录例外判断的理由 |
| Week 6 | 调用完整判断链，每个事实附可点溯源角标 |
| Week 8 | 项目隔离，跨项目引用需显式确认 |
| Week 11 | 纠正生成新版本，旧版本归档并标记下游引用 |

输入框支持自由交互：输入「记住…」走确认流程，输入含「记错了」走纠错定位。

## 技术说明

纯静态页面，原生 HTML / CSS / JavaScript，无第三方依赖。本地双击 `index.html` 即可运行。
